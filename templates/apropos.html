À propos du projet

Présentation

Cette application a été développée dans le cadre de la SAE 2.01 du BUT Informatique à l'IUT de Créteil-Vitry.

Son objectif est de permettre la consultation et l'analyse de données de santé en France à partir des informations fournies par l'Assurance Maladie.

Fonctionnalités

  • Consultation des effectifs des professionnels de santé
  • Analyse des densités par territoire
  • Consultation des honoraires
  • Analyse des prescriptions
  • Visualisation graphique des données
  • Export CSV et PDF

Technos utilisées

  • Python
  • Flask
  • SQLAlchemy
  • MySQL
  • HTML / CSS / JavaScript

Architecture MVC

Le projet suit l'architecture MVC (Modèle - Vue - Contrôleur).

  • Modèle : accès aux données et API
  • Vue : pages HTML et affichage
  • Contrôleur : routes Flask et traitement des requêtes

Sources des données
